# Trip document template

Write in the traveller's language. Keep it scannable: the traveller opens this
on a phone on a platform.

## 1. Overview

- Who, dates, pass (type, class, days, validity, home country).
- Route in one line, e.g. `Breda -> Milano -> Nice -> Madrid -> Granada -> ... -> Utrecht`.
- Fixed anchors (holidays, visits) and what is still flexible.
- Travel days used / left (from the counter).

## 2. Day by day

One block per day:

```text
Wed 23 Dec - Madrid -> Cordoba            [travel day 4/10]
  Train: AVE 02092, 10:05 -> 11:52, reservation: booked (ref ...)
  Stay: ...
  Plan: one anchor + one backup, coffee/food tips from the preference profile
```

Mark rest days (no travel day used) clearly.

## 3. Reservation tracker

Sorted by "book by", earliest first:

| Book by | Leg | Train | Fee | Quota | Channel | Status |
|---|---|---|---|---|---|---|

## 4. Pass and app checklist

- Pass activated with the right start date; passport number entered.
- Before each travel day: activate the day, add every leg, show ticket works.
- Open the app online daily; power bank; ID; pass number stored off the phone.
- Reservations saved as PDF (printed where required).

## 5. Open questions

What is unconfirmed, who can answer it, and by when it matters.

## 6. Sources

Official pages used for fees and timetables, with check date.
